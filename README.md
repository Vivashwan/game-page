# Gaming Gadgets on Rent: UI recreation

A static HTML/CSS/JS recreation of a rental marketplace's "Gaming gadgets on rent" listing page, built as a front-end exercise.

## Run

Open `index.html` in a browser. No build step. Fonts load from Google Fonts.

## Files

- `index.html`: page markup and the inline SVG icon sprite
- `styles.css`: all styling, with responsive breakpoints at 1100px and 760px
- `app.js`: sidebar filtering, product grid with paging, FAQ accordion, reviews carousel, footer links, date picker with rental-price calculation
- `products.js`: product data (name, tag, per-day rent, stock status)

Brand name, imagery, reviews and long-form copy are placeholders.
